# 유체역학(+유체기계 응용) — 시험형 완성 자료

목표: 정수압·연속방정식·베르누이·운동량·관마찰을 확실히 회수하고, 펌프·수차·캐비테이션을 응용으로 연결한다.

## 0. 계산 루틴

1. 기준면과 유선/관로를 그린다.
2. 단면 1, 2를 표시한다.
3. P, V, z, A, ρ를 표로 정리한다.
4. 정상/비정상, 비압축성 여부를 확인한다.
5. 연속/베르누이/운동량 중 핵심식을 선택한다.
6. 펌프·터빈·손실수두가 있으면 식에 추가한다.

---

# 1. 유체의 성질

- 밀도 `ρ=m/V`
- 비중량 `γ=ρg`
- 비체적 `v=1/ρ`
- 비중 SG = 물 기준 밀도비
- 점성: 층간 상대운동에 저항하는 성질
- 동점성계수 `ν=μ/ρ`
- 표면장력, 모세관 현상, 증기압

뉴턴유체 대표식:
`τ = μ du/dy`.

# 2. 정수압

정지유체:
`dp/dz = -ρg`

같은 유체에서 깊이 h만큼 내려가면 압력 증가:
`p = p0 + ρgh`.

파스칼 원리: 밀폐유체에 가한 압력은 각 방향으로 전달.

# 3. 평면에 작용하는 정수력

평면에 작용하는 합력:
`F = ρg h_c A`

h_c는 면적도심의 자유수면으로부터 깊이.

압력중심은 일반적으로 수직평면에서 도심보다 더 깊은 위치에 있다.

# 4. 부력

아르키메데스 원리:
부력 = 밀어낸 유체의 무게.

`F_B = ρ_f g V_displaced`.

뜨는 물체 평형에서는 물체중량=부력.

# 5. 유량과 연속방정식

체적유량:
`Q = AV`

질량유량:
`ṁ = ρAV`

정상 비압축성 1차원:
`A1V1 = A2V2`.

관이 좁아지면 속도는 증가한다.

# 6. 베르누이 방정식

이상적 정상 비압축성 유선흐름:
`P/γ + V²/(2g) + z = constant`

실제 관로 확장형:
`P1/γ + V1²/2g + z1 + h_p - h_t = P2/γ + V2²/2g + z2 + h_L`

- 압력수두 P/γ
- 속도수두 V²/2g
- 위치수두 z
- 펌프수두 hp
- 터빈수두 ht
- 손실수두 hL

# 7. 운동량 방정식

제어체적에 대해 힘과 운동량 변화율을 연결한다.

1차원 단순형:
`ΣF = ṁ(V_out - V_in)`.

노즐 반력, 제트가 판에 미치는 힘, 굽은 관의 지지력 문제에 사용.

# 8. 레이놀즈수

`Re = ρVD/μ = VD/ν`.

원형관 기준:
- 층류: 대략 Re < 2300
- 천이: 중간영역
- 난류: 대략 Re > 4000

시험에서는 정확한 경계보다 `무차원수의 의미`와 흐름 구분을 먼저 회수한다.

# 9. 관마찰

Darcy-Weisbach:
`h_f = f (L/D) V²/(2g)`.

층류 원형관에서 Darcy 마찰계수:
`f = 64/Re`.

국부손실:
`h_m = K V²/(2g)`.

직렬관은 손실수두가 합산된다.

# 10. 경계층과 항력

고체표면에서 점성 때문에 속도가 0인 no-slip 조건을 적용한다.

- 경계층: 벽면 영향이 큰 얇은 유동영역
- 박리: 불리한 압력구배 등으로 경계층이 표면에서 떨어짐
- 항력: 유동방향 힘
- 양력: 유동방향에 수직한 힘 성분

# 11. 차원해석

Buckingham π 정리의 목적: 많은 변수를 무차원군으로 줄여 실험/상사관계를 정리.

대표 무차원수:
- Reynolds: 관성력/점성력 성격
- Froude: 관성력/중력 성격
- Mach: 유속/음속

# 12. 펌프

펌프는 유체에 에너지를 공급해 수두를 높인다.

수력동력:
`P_h = ρgQH`.

축동력이 Pshaft이고 효율 η라면 보통
`η = P_h/P_shaft`.

원심펌프 핵심:
- 임펠러 회전으로 유체에 에너지 전달
- 캐비테이션 주의
- 흡입조건/NPSH 중요

# 13. 수차

수차는 유체의 수력에너지를 축동력으로 바꾼다.

대표:
- 펠톤: 고낙차·저유량, 충동형
- 프란시스: 중간범위, 반동형
- 카플란: 저낙차·대유량, 축류 반동형

# 14. 캐비테이션

국부압력이 액체의 증기압 이하로 내려가 기포가 생기고 이후 붕괴하는 현상.

문제:
- 소음/진동
- 임펠러 침식
- 성능저하

방지 방향:
- 흡입압력 확보
- 펌프 설치높이 조정
- 유체온도/증기압 고려

---

# 15. 자주 틀리는 포인트

- 베르누이는 모든 상황에 무조건 적용하는 식이 아니다.
- 압력이 높다고 속도가 반드시 낮은 것은 아니다. 높이·손실·펌프 등 전체 에너지항을 봐야 한다.
- 정수압은 같은 깊이에서 방향과 무관하게 같은 크기.
- 연속식은 질량보존식이며 압축성일 때 단순 AV 일정이 아닐 수 있다.
- 펌프 효율식에서 수력동력과 축동력의 분자/분모를 바꾸지 않는다.
- 캐비테이션은 압력이 너무 높아서 생기는 것이 아니라 국부압력이 증기압 이하로 낮아질 때 발생.
