# choi — 철도공기업 기계직 학습 과정

서울교통공사·부산교통공사·코레일 기계직 대비를 위한 장기 학습 폴더입니다.

## 목표

- 법령 제외
- **수리능력만 40~50점 방어 목표**
- 그 외 전공·NCS 영역은 **80점권 목표**
- 시험일정에 끌려가지 않고 실력을 누적하는 장기 과정
- 토·일은 정규 학습에서 제외
- 평일 기본 순공 **주 28시간**: 월~목 6시간, 금 4시간. 금요일 추가 2시간은 선택 보충으로만 사용

## 최우선 원칙

과목 순서는 난이도보다 **여러 기관에 재사용되는 범위**를 우선합니다.

1. 서울교통공사·부산교통공사·코레일 **3기관 공통**
2. 3기관 공통을 만든 뒤, 최소 추가시간으로 한 기관의 전 범위를 빠르게 완성하기 위해 **서울교통공사+코레일 공통인 열역학**
3. **서울교통공사+부산교통공사 공통**
4. 마지막에 **서울교통공사 추가 범위**

즉, 단순히 '공통과목부터'가 아니라 **한 곳 이상 합격할 확률을 높이는 방향으로 공통 범위를 확장**합니다.

세부 주차별 계획, 과목별 목표시간, 진도 이동 기준은 [CURRICULUM.md](./CURRICULUM.md)에 정리합니다.
