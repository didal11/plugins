# 전공 세부 커리큘럼

이 문서는 `CURRICULUM.md`의 전공 파트를 실제 단원 수준까지 내려서 정리한 실행안이다.

## 공통 학습 규칙

모든 계산과목은 아래 순서를 고정한다.

1. 현상을 그림으로 이해
2. 물리량과 단위를 확인
3. 식이 왜 생기는지 이해
4. 가장 쉬운 숫자로 계산
5. 기본문제 5~10개
6. 기출/혼합문제
7. 오답을 개념·공식선택·계산실수·단위실수로 분류

공식카드는 `공식만` 적지 않는다.

- 앞면: 어떤 상황에서 무엇을 구하는가
- 뒷면: 공식, 단위, 자주 하는 실수, 간단한 예시

---

# 1. 기계재료 — 60~75h

## 목표

암기만 하는 과목이 아니라 `조직 변화 → 성질 변화 → 용도`를 연결해서 80점권을 만든다.

## 단원 순서

### 1단계: 재료의 기초
- 금속결합과 결정구조
- 결정격자와 결함
- 탄성/소성 변형
- 연성/취성
- 강도·경도·인성

### 2단계: 재료시험
- 인장시험
- 경도시험
- 충격시험
- 피로시험
- 크리프
- 비파괴검사 기초

### 3단계: 철강재 핵심
- Fe-C 상태도
- 공석·공정·포정 개념
- 페라이트, 오스테나이트, 시멘타이트, 펄라이트
- 탄소함량에 따른 성질
- 탄소강 분류와 용도

### 4단계: 열처리
- 풀림
- 불림
- 담금질
- 뜨임
- 표면경화
- 항온·연속냉각의 의미
- 마텐사이트/베이나이트 등 조직 변화

### 5단계: 합금강·주철
- 합금원소 역할
- 구조용 합금강
- 공구강/스테인리스강
- 회주철·백주철·구상흑연주철·가단주철

### 6단계: 비철금속
- Al계
- Cu계
- Mg계
- Ti계
- 베어링합금
- 초경합금

### 7단계: 소성가공과 재료성질 연결
- 냉간/열간가공
- 가공경화
- 재결정
- 결정립과 강도

## 추천 시간

- 이론 구조화 25h
- 단원문제 15h
- 기출/혼합 15h
- 누적복습 5~20h

## 완료 기준

- Fe-C 상태도를 보고 주요 조직을 설명
- 열처리 4종을 목적/냉각/결과로 비교
- 합금원소의 대표 효과를 비교
- 혼합세트 제한시간 평균 80점 이상

# 2. 재료역학 — 130~160h

## 목표

수학공식을 외우는 과목으로 느끼지 않게 하고, `힘 → 응력 → 변형 → 부재 거동`의 한 흐름으로 만든다.

## 선행 수학 최소 모듈

필요한 순간에만 학습한다.

- 분수 계산
- 단위변환
- 비례식
- 문자 이항
- 제곱/제곱근
- 원의 면적·단면
- 아주 기초적인 삼각비

## 단원 순서

### 1단계: 응력과 변형률
- 하중과 반력의 개념
- 수직응력
- 전단응력
- 수직변형률
- 전단변형률
- 훅의 법칙
- 탄성계수 E, G, K
- 포아송비

### 2단계: 축하중
- 직렬/병렬 부재
- 자중
- 변단면
- 열응력
- 부정정 기초

### 3단계: 비틀림
- 토크
- 극관성모멘트
- 전단응력
- 비틀림각
- 동력전달축 연결

### 4단계: 보의 기본
- 지점과 반력
- 전단력
- 굽힘모멘트
- SFD/BMD

### 5단계: 단면성질
- 도심
- 단면1차모멘트
- 단면2차모멘트
- 평행축정리
- 단면계수

### 6단계: 굽힘
- 굽힘응력
- 전단응력
- 조합응력 기초

### 7단계: 처짐
- 탄성곡선
- 대표 보의 처짐
- 중첩법 기초

### 8단계: 좌굴·에너지
- 오일러 좌굴
- 세장비
- 변형에너지
- 충격하중 기초

## 계산문제 루틴

모든 문제에서 먼저 5줄을 적는다.

1. 구할 것
2. 주어진 값
3. 단위
4. 해당 현상
5. 사용할 식

그 뒤 숫자를 넣는다.

## 완료 기준

- 그림에서 하중과 반력을 표시 가능
- SFD/BMD 기본형을 직접 그림
- 인장/비틀림/굽힘 중 어떤 식을 써야 하는지 구분
- 제한시간 혼합세트 평균 80점 이상

# 9. 전공 누적복습 규칙

과목을 끝낸 뒤에도 아래 주기를 유지한다.

- 완료 다음날: 오답만 20~30분
- 1주 후: 10~20문항
- 3주 후: 혼합 20문항
- 6주 후: 제한시간 혼합세트
- 이후: 월 1회 전공 전체 랜덤세트

점수가 70점 아래로 떨어지면 해당 과목을 `완료`에서 `보강` 상태로 되돌린다.
