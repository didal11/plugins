# 주간 실행 시스템

이 문서는 커리큘럼을 실제 생활 속에서 굴리기 위한 운영 규칙이다.

## 1. 기본 시간표

### 월~목: 순공 6시간

- Block A 2h: 가장 어려운 전공 신규개념
- Block B 2h: 전공 예제·문제풀이
- Block C 2h: NCS

### 금요일: 순공 4시간

- Block A 2h: 주간 전공 오답/복습
- Block B 2h: NCS 주간세트 + 기록

금요일 추가 2시간은 선택이다. 반드시 해야 하는 진도를 금요일 선택시간에 넣지 않는다.

### 토·일

정규 공부 0시간.

밀린 진도를 주말에 강제로 메우지 않는다. 밀렸다면 다음 주 계획을 뒤로 미룬다.

---

# 2. 한 블록의 실제 구성

2시간을 한 번에 버티지 않는다.

권장:

- 50분 공부
- 10분 휴식
- 50분 공부
- 10분 정리/휴식

집중이 잘 안 되는 날은 25/5 방식으로 쪼개도 된다.

중요한 것은 앉아 있던 시간이 아니라 **실제 순공시간**이다.

---

# 3. 전공 신규개념 Block A

순서:

1. 오늘 배울 범위를 5분 안에 확인
2. GPT에게 전체 흐름 설명 요청
3. 교재 이론 읽기
4. 이해가 안 되는 문장만 GPT에게 다시 질문
5. 공식은 유도 의미까지 확인
6. 책을 닫고 5분 구두설명

### GPT 질문 템플릿

`나는 이 공식을 통암기하기 어렵다. 이 식이 어떤 물리상황에서 왜 나오는지, 중학생 수준의 수학으로 그림을 떠올릴 수 있게 설명하고 마지막에 시험에서 식을 고르는 기준까지 알려줘.`

GPT 답을 그대로 노트로 옮기지 않는다. 이해한 뒤 자기 말 3~5줄로 다시 쓴다.

---

# 4. 전공 문제풀이 Block B

문제는 세 단계로 푼다.

### 1단계 — 바로 풀기

3분 내 방향이 잡히는 문제.

### 2단계 — 학습문제

방향은 알지만 공식이나 계산이 막히는 문제.

### 3단계 — 보류문제

처음부터 무엇을 해야 할지 모르는 문제.

한 문제 때문에 20분 이상 진도를 멈추지 않는다.

보류문제는 별도 표시 후 GPT/해설로 개념을 다시 잡는다.

---

# 5. 계산문제 7단계

계산이 약한 것을 고려해 모든 계산문제에서 같은 양식을 사용한다.

1. 그림
2. 구할 값
3. 주어진 값
4. 단위 통일
5. 현상 이름
6. 공식 선택
7. 숫자 대입

계산실수 시 정답만 고치지 않는다.

실수 종류를 기록한다.

- 사칙연산
- 소수점
- 단위
- 부호
- 공식 변형
- 문제조건 누락

같은 실수가 3번 나오면 그 계산만 10문제 미니훈련한다.

---

# 6. NCS Block C

초반에는 한 영역을 2시간 몰아서 하지 않는다.

예:

- 50분 의사소통
- 10분 휴식
- 50분 문제해결

수리일에는:

- 30분 기초계산
- 20분 쉬운 자료해석
- 나머지는 다른 영역

수리는 정답률을 높이되 고난도에 시간을 쓰지 않는다.

---

# 7. 오답노트는 짧게

오답 하나당 최대 4줄.

1. 틀린 이유
2. 정답의 핵심근거
3. 다시 틀리지 않을 규칙
4. 재풀이 날짜

문제를 통째로 베껴 적지 않는다.

---

# 8. 복습 스케줄

새로 배운 내용은 다음 주기로 본다.

- D+1: 10~20분
- D+7: 문제 5~10개
- D+21: 혼합문제
- D+42: 제한시간 세트

이후 월 1회 랜덤세트.

망각이 심한 과목은 D+3을 추가한다.

---

# 9. 하루가 망한 경우

순공 6시간을 못 했다고 다음날 12시간 하지 않는다.

### 4시간 한 날

그날 완료로 인정. 2시간은 다음 주 계획을 2시간 미룬다.

### 2시간 이하 한 날

그날은 `저강도일`로 기록하고 다음 날 정상 6시간으로 복귀한다.

### 하루를 완전히 쉰 날

주말 보충 금지. 커리큘럼 종료일을 하루 뒤로 민다.

계획을 지키기 위해 생활을 망가뜨리지 않는다.

---

# 10. 의욕이 떨어질 때 최소선

완전 중단을 막기 위한 최소학습은 평일 **2시간**이다.

- 전공 복습 1h
- NCS 1h

2시간만 하고 종료해도 된다.

단, 이런 날이 2주 연속 주 3회 이상 발생하면 총 공부시간 목표를 주 28h에서 주 24h로 공식 하향하고 지속성을 우선한다.

---

# 12. 4주마다 커리큘럼 보정

4주마다 예상시간과 실제성적을 비교한다.

### 예상보다 빠른 과목

최근 3세트 85점 이상이면 신규학습 시간을 줄이고 유지복습으로 전환한다.

### 예상대로인 과목

현재 시간배분 유지.

### 예상보다 느린 과목

단순히 시간을 더 넣기 전에 원인을 찾는다.

- 설명이 이해 안 됨 → 설명자료/교재 변경
- 공식선택이 안 됨 → 유형분류 훈련
- 계산이 틀림 → 계산 미니훈련
- 기억이 안 남 → 복습 간격 단축
- 시간 부족 → 제한시간 세트 추가

---

# 13. 교재 추가 구매 기준

새 책은 다음 중 하나일 때만 산다.

1. 위을복 설명을 GPT 도움을 받아도 이해가 안 되는 계산과목
2. 단원별 기본문제가 부족함
3. 실제 기관형 기출/모의세트가 부족함

비슷한 기본서를 여러 권 사서 처음부터 반복하지 않는다.

### 우선순위

- 이해용 보조교재 1권
- 문제용 기출/문제집 1권
- 기관별 실전모의 1권

이 정도면 충분하다.

---

# 14. 기관별 실전세트 기록

Phase G에서는 다음을 반드시 기록한다.

```text
기관:
세트번호:
총점:
전공점수:
NCS점수:
시간초과 문항:
버린 문항:
찍은 문항:
계산실수:
독해실수:
다시 풀면 맞힌 문항:
```

`다시 풀면 맞힌 문제`가 많으면 지식부족보다 시간관리 문제가 크다는 뜻이다.

---

# 15. 가장 중요한 운영원칙

커리큘럼의 성공 기준은 하루 최고 공부시간이 아니다.

**평일 28시간을 몇 달 동안 반복할 수 있느냐**가 핵심이다.

한 번 많이 공부하는 것보다 월~금의 반복성을 우선한다.
