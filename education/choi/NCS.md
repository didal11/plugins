# NCS 세부 커리큘럼 — 유형 단위 운영본

수리능력만 **40~50점 방어**, 나머지 영역은 **80점권**을 목표로 한다.

이 문서의 핵심 변경점은 `의사소통 1h`, `문제해결 1h`, `수리 1h`처럼 영역명만 적지 않는 것이다. 앞으로 모든 일간 계획·학습지·캘린더에는 반드시 아래처럼 **영역 + 하위능력 + 실제 문제유형**까지 적는다.

예:

- `의사소통-문서이해: 주제·요지·핵심문장`
- `문제해결-사고력: 순서·위치배치 조건추리`
- `수리-연산: 비율·백분율·증감률`
- `자원관리-시간/인적: 일정표·근무배정`

---

# 0. 공식 NCS 체계와 시험 커리큘럼 표기 원칙

공기업 채용공고에는 아직 `의사소통·수리·문제해결·자원관리·정보·조직이해·기술·대인관계·직업윤리·자기개발` 같은 기존 직업기초능력 영역명이 사용되는 경우가 많다. 따라서 **시험 대비 표기는 해당 기관 공고의 영역명을 우선**한다.

다만 NCS 누리집은 2026년 직업공통능력 개편 체계도 제공한다.

- 의사소통: 기존 문서이해·문서작성 등을 `문서소통능력` 중심으로 재구성
- 수리: `연산능력 / 통계활용능력 / 도표활용능력`
- 문제해결: 기존 사고력·문제처리를 `문제분석 / 대안발굴 / 의사결정` 방향으로 재구성
- 정보능력은 개편 체계에서 디지털능력과 연결

우리 커리큘럼은 **공고에 적힌 영역명 + 공식 하위능력 + 실전 문제형식**을 같이 표시한다.

# 1. 의사소통능력 — 100~140h / 목표 80

공식 구 직업기초능력의 하위능력은 문서이해·문서작성·경청·의사표현·기초외국어이며, 2026 개편 체계에서는 문서소통·구두소통·외국어소통으로 재구성된다.

실전 대비에서는 아래 유형으로 더 잘게 나눈다.

## C1 문서이해 — 주제·요지·핵심문장

출제 신호:
- 글의 중심내용
- 필자의 주장
- 제목/주제로 적절한 것
- 가장 핵심적인 문장

훈련:
1. 문제 먼저 확인
2. 첫 문단의 역할 확인
3. 역접 뒤 결론 표시
4. 반복되는 핵심어 표시
5. 근거 없는 상식선지 제거

## C2 문서이해 — 세부내용 일치/불일치

출제 신호:
- 본문과 일치하는 것
- 알 수 없는 것
- 적절하지 않은 것

훈련:
- 선지마다 본문의 근거 위치를 찾는다.
- `비슷한 말`과 `같은 말`을 구분한다.
- 수치·범위·주체·조건·예외를 표시한다.

## C3 문서이해 — 문단 역할·논리흐름·문장배열

유형:
- 문단의 기능
- 문장 순서
- 들어갈 위치
- 앞뒤 문장의 연결

핵심표시:
`원인 → 결과`, `문제 → 해결`, `주장 → 근거`, `일반 → 구체`, `시간순서`

## C4 문서이해 — 빈칸·접속어·문맥

유형:
- 빈칸에 들어갈 내용
- 접속어 선택
- 문맥상 의미

먼저 앞뒤 관계를 `같은 방향 / 반대 / 원인결과 / 예시` 중 하나로 정한다.

## C5 업무문서 — 목적·수신자·핵심정보

자료:
- 공문
- 이메일
- 안내문
- 지침
- 회의자료
- 보고서

문제:
- 문서의 목적
- 담당자가 해야 할 행동
- 기한/대상/예외
- 필요한 후속조치

## C6 문서작성 — 개조식·요약·보고순서

유형:
- 가장 적절한 문서작성 방식
- 문장의 배치
- 핵심정보 요약
- 보고서/메일 구조

## C7 문서작성 — 문장다듬기·표현오류

유형:
- 중복표현
- 불명확한 주어
- 목적에 맞지 않는 표현
- 지나치게 장황한 문장

## C8 구두소통 — 경청·대화의도·적절한 응답

유형:
- 상대의 핵심 요구
- 적절한 피드백
- 상황에 맞는 설명
- 오해를 줄이는 질문

## C9 긴 지문 — 정보검색형

모든 문장을 완벽히 이해하려 하지 않는다.

`질문 → 키워드 → 해당 구간 탐색 → 근거 확인`

순으로 푼다.

## C10 의사소통 실전혼합

C1~C9를 섞되 다음 오답코드를 기록한다.

- C-R1: 주제를 잘못 잡음
- C-R2: 근거 위치를 못 찾음
- C-R3: 범위/예외를 놓침
- C-R4: 문장관계를 잘못 읽음
- C-T: 시간초과

# 2. 문제해결능력 — 60~80h / 목표 80

공식 구 체계는 `사고력 / 문제처리능력`, 개편 방향은 `문제분석 / 대안발굴 / 의사결정`과 연결된다.

실전은 아래 유형으로 나눈다.

## P1 명제·조건문·참/거짓

- A이면 B
- A가 아니면?
- 반드시 참 / 반드시 거짓 / 알 수 없음

조건을 문장으로만 들고 있지 말고 기호화한다.

## P2 순서·위치배치

- 사람 순서
- 좌석
- 작업순서
- 층/위치 배치

`고정조건 → 직접조건 → 간접조건` 순으로 표에 넣는다.

## P3 규칙·패턴

- 숫자/문자 규칙
- 도식 변화
- 반복패턴
- 규칙 적용 결과

첫 두 단계에서 규칙이 안 보이면 오래 붙잡지 않는다.

## P4 문제분석 — 원인·문제정의

- 원인과 결과 구분
- 핵심문제 찾기
- 증상과 원인 구분
- 필요한 정보 고르기

## P5 대안선택·우선순위·의사결정

- 가장 적절한 대안
- 기준별 선택
- 장단점 비교
- 의사결정표

기준을 먼저 열로 만들고 대안을 행으로 둔다.

## P6 일정·업무배정

- 담당자 배정
- 일정배치
- 회의/작업시간
- 조건을 만족하는 경우 찾기

## P7 절차·프로세스

- 업무 흐름
- 선후관계
- 누락단계
- 오류가 발생한 지점

## P8 복합조건 추리

조건이 3개 이상이면 반드시 외부화한다.

사용 도구:
- O/X표
- 순서선
- 2차원 표
- 화살표

## P9 자료조건 결합

표·규정·조건문을 동시에 읽고 적용하는 유형.

`자료에서 사실 추출 → 조건 적용 → 후보 제거`

## P10 실전혼합·선별

- 30초 내 구조가 보이는 문제: 풀이
- 구조는 보이지만 계산/경우가 많음: 표시 후 후순위
- 구조 자체가 안 보임: 즉시 넘김

오답코드:
- P-C: 조건 누락
- P-I: 추론 오류
- P-V: 표/그림 정리 실패
- P-D: 대안선택 기준 오류
- P-T: 시간초과

# 3. 수리능력 — 30~50h / 목표 40~50

수리는 80점 목표가 아니다. **회수 가능한 쉬운 문제를 안정적으로 맞히는 방어영역**이다.

공식 개편 체계는 `연산능력 / 통계활용능력 / 도표활용능력`이다.

## Q1 연산 — 사칙·분수·소수

- 분수↔소수
- 괄호
- 음수
- 빠른 약분

## Q2 연산 — 비율·백분율·증감률

가장 중요.

- 구성비
- 전년대비 증감
- 할인/인상
- 비율 비교

## Q3 연산 — 단위환산·어림값

- 시간
- 길이
- 질량
- 금액 단위
- 천/만/백만

복잡한 정확계산보다 먼저 답의 크기를 추정한다.

## Q4 통계 — 평균·가중평균

- 단순평균
- 전체평균
- 그룹별 인원수가 다른 평균

## Q5 통계 — 비중·빈도·기초확률

우선순위는 Q1~Q4보다 낮다.

복잡한 경우의 수·확률은 시간 대비 효율이 낮으면 버린다.

## Q6 도표 — 표 읽기·단순비교

- 최대/최소
- 순위
- 합계
- 차이

## Q7 도표 — 그래프 증감·추세

- 증가/감소
- 변화폭
- 증가율
- 추세비교

## Q8 도표 — 자료계산·비율비교

표에서 숫자를 2~3개 꺼내 계산하는 문제.

## Q9 응용계산 — 거리·속력·시간

쉬운 형태만 확보한다.

## Q10 응용계산 — 일률·작업량

공식 자체보다 `전체 작업량 = 일률 × 시간` 구조를 먼저 이해한다.

### 수리 선별 규칙

20~30초 내 계산경로가 안 보이면 넘긴다.

목표:
- Q1~Q4: 높은 정확도
- Q6~Q8: 쉬운 도표문제 회수
- Q9~Q10: 기본형만
- 복잡한 확률/다중자료/장계산: 후순위

## Day 231~270 — 기관별 실전

### 서울교통공사

10영역을 실제 세트에 섞되 기록은 다음처럼 남긴다.

### 부산교통공사

공고상 5영역을 기준으로
`의사소통 C / 수리 Q / 문제해결 P / 자원관리 R / 정보 I`
를 유형별로 태깅한다.

### 코레일

당해 최신 공고와 최신 복원형 세트의 구조를 먼저 확인한다. 과거 기관 이미지로 영역을 영구 고정하지 않는다.

실전세트에서 최소한 다음을 따로 기록한다.
- 문서이해형
- 자료/도표형
- 조건추리형
- 계산형
- 모듈지식형
- 시간초과형

# 13. 성적판정도 영역이 아니라 유형별로 한다

예:

| 영역 | 유형 | 최근 정답률 | 평균시간 | 판단 |
|---|---|---:|---:|---|
| 의사소통 | C1 주제/요지 | 88% | 55초 | 유지 |
| 의사소통 | C2 일치/불일치 | 68% | 85초 | 보강 |
| 문제해결 | P2 순서배치 | 82% | 90초 | 유지 |
| 수리 | Q2 비율/증감 | 55% | 75초 | 방어 성공 |
| 수리 | Q8 자료계산 | 25% | 150초 | 후순위 |

수리 외 영역은 유형별 최근 3세트 평균 80%를 목표로 한다.

수리는 `Q1~Q4 + 쉬운 Q6~Q8`에서 70~80%를 확보해 전체 40~50점을 만드는 것을 우선한다.

이제 모든 캘린더/학습지의 NCS 칸에는 단순히 `의사소통 + 수리`가 아니라 **`C2 문서일치 + Q2 비율·증감` 같은 유형명이 표시되어야 한다.**
