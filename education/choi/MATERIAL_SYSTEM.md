# 시험역산형 학습자료 설계 시스템

이 문서는 `choi` 과정에서 실제 수업자료를 어떻게 만들지 정의한다. 핵심 원칙은 **교과서 목차 순서대로 설명하는 자료가 아니라, 실제 철도공기업 필기에서 요구되는 판단·속도·문제형식을 역산해 자료를 만든다**는 것이다.

## 1. 자료 근거 우선순위

1. 당해 연도 공식 채용공고 및 공식 출제범위
2. 최근 기출복원 자료와 기출복원 교재
3. 현행 기관별 전공 문제집의 목차와 난도구성
4. 일반기계기사·공무원 기계일반 등 유사 시험 문제는 **연습문제 공급원**으로만 사용
5. 응시후기는 체감난도와 시간압박 참고용

공식 문제지가 전부 공개되는 시험이 아니므로, 확인되지 않은 `최근 5년 XX단원 17% 출제` 같은 정밀 빈도는 만들지 않는다.

## 2. 한 단원 자료는 6개 층으로 만든다

### Layer A — 시험지도
단원 시작 전에 1페이지로 끝낸다.

- 이 단원이 어느 기관 범위에 들어가는가
- 시험에서 어떤 형태로 물을 수 있는가
- 반드시 맞혀야 할 핵심과 후순위 내용
- 계산 필요 여부
- 선수개념

### Layer B — 개념 골격
설명은 `정의 → 현상/그림 → 비교 → 시험선지` 순서로 만든다.

한 개념을 장황하게 강의하지 않고, 객관식 선지에서 구별할 수 있을 정도의 구조를 먼저 만든다.

### Layer C — 선지 판별 훈련
처음부터 4지선다만 풀리지 않는다. 먼저 짧은 O/X·맞는 설명 고르기·두 개념 비교를 사용한다.

목적은 `정답을 기억`하는 것이 아니라 `틀린 문장의 틀린 지점`을 찾는 것이다.

### Layer D — 시험형 문제
문제는 아래 태그를 붙인다.

- `D`: 직접 지식/정의
- `C`: 개념 비교
- `G`: 그림·선도·상태도
- `F`: 공식 선택
- `N1`: 한 단계 수치계산
- `N2`: 두 단계 이상 계산
- `M`: 개념+계산 혼합

각 문제에는 `단원`, `태그`, `난도`, `예상 제한시간`, `오답원인`을 기록한다.

### Layer E — 압축노트
단원 종료 후 새 요약노트를 다시 만드는 것이 아니라, 틀린 것만 남긴다.

- 헷갈린 비교 5~15개
- 외워야 하는 수치/분류
- 자주 잘못 선택한 공식
- 그림 하나

### Layer F — 제한시간 미니세트
단원마다 마지막에 10~20문항을 시간 제한으로 푼다. 1회독 이후에는 단원별 세트보다 혼합세트 비중을 높인다.

---

## 3. 문제를 만드는 원칙

기출복원 문제를 장문 그대로 베끼지 않는다. 공개된 자료에서 **출제개념·질문방식·난도·함정 구조**를 추출하고, 숫자·상황·선지를 바꾼 신규 문제를 제작한다.

예:

- 복원자료가 `열처리 목적 구별`을 묻는다면 → 풀림/불림/담금질/뜨임 비교 신규문제 제작
- `응력 계산`이 반복되면 → 단위와 단면 형상을 바꿔 N1 문제 제작
- `P-V 선도`를 묻는 유형이 확인되면 → 그림 해석과 과정 판별 문제를 따로 제작

문제은행은 `출처 근거`와 `문제 본문`을 분리한다. 출처는 어떤 유형을 반영했는지를 기록하는 용도다.

## 4. 전공 자료 구조

### 기계재료
자료 순서:

1. 기계적 성질 + 응력-변형률선도
2. 재료시험
3. 결정·조직 기초
4. Fe-C 상태도
5. 열처리
6. 탄소강/합금강
7. 주철
8. 비철금속
9. 비금속·신소재
10. 누적 혼합

핵심 문제형식은 `D/C/G`를 먼저 확보하고 계산은 재료시험의 쉬운 `N1` 수준부터 넣는다.

### 재료역학
자료 순서:

1. 힘·하중·응력·변형률
2. 훅의 법칙·탄성계수·포아송비
3. 축하중/열응력
4. 비틀림
5. 보의 반력
6. SFD/BMD
7. 단면2차모멘트
8. 굽힘응력
9. 처짐
10. 좌굴

모든 공식은 `그림 → 어떤 힘이 걸리는가 → 무엇을 구하는가 → 식 → 단위 → 숫자` 순서로 가르친다.

### 기계설계
기계요소의 기능을 먼저 이해한 뒤 재료역학 식을 연결한다.

- 나사/볼트
- 리벳/용접
- 키/핀
- 축
- 베어링
- 기어
- 벨트/체인
- 스프링
- 브레이크/클러치
- 축이음

### 열역학
현상과 상태변화를 먼저 잡는다.

- 상태량·과정량
- 압력/온도/비체적
- 이상기체
- 열과 일
- 내부에너지/엔탈피
- 1법칙
- 정압/정적/등온/단열
- 2법칙/엔트로피
- 사이클
- 증기/냉동/열전달/내연기관 연계

`F → N1 → N2` 순서로 계산 난도를 올린다.

### 유체역학

- 유체 성질/압력
- 정수압
- 연속방정식
- 베르누이
- 운동량
- 관로손실
- 차원해석/상사
- 개수로/압축성 기본
- 펌프·수차·송풍기 등 유체기계 응용

### 기계공작·제작법 / 유압기기 / 열전달
공통코어 이후에 기관 차이 범위로 붙인다. 이론형 자료는 비교표와 선지판별 비중을 높이고, 계산이 필요한 단원만 공식 블록을 추가한다.

## 5. NCS 자료 구조

NCS는 이론강의보다 `진단 → 유형규칙 → 짧은 반복 → 제한시간`을 중심으로 만든다.

### 의사소통
- 제목/주제/요지
- 사실일치
- 문단관계
- 공문/업무문서
- 문장배열
- 긴 지문 선별읽기

### 문제해결
- 조건표
- 순서/배치
- 참거짓
- 규칙찾기
- 의사결정
- 업무상황형

### 수리
목표는 40~50점 방어다.

- 사칙·분수·소수
- 비율/백분율
- 평균/증감률
- 속력/시간/거리
- 쉬운 표·그래프
- 쉬운 자료해석

고난도 자료해석을 오래 붙잡지 않는다.

### 나머지 NCS
자원관리·정보·조직이해·대인관계·직업윤리·자기개발·기술은 실제 해당 기관 범위가 열릴 때 `모듈개념 30~40% + 상황형/문제 60~70%`로 구성한다.

---

## 6. 한 수업 2시간의 표준 템플릿

- 0~10분: 전날 회상 5문항
- 10~40분: 개념 골격
- 40~60분: 비교/그림/선지 판별
- 60~65분: 짧은 휴식
- 65~95분: 시험형 10~15문항
- 95~115분: 오답 해설 및 변형 3~5문항
- 115~120분: 압축기록

수업자료는 강의노트가 아니라 `이해 → 판별 → 문제 → 오답`이 한 파일 안에서 끝나도록 만든다.

---

## 7. 자료 난도 운영

처음부터 어려운 문제를 많이 풀리지 않는다.

- `L1`: 정의와 직접개념
- `L2`: 비교/기본 공식
- `L3`: 실제 시험에서 맞혀야 할 중간 난도
- `L4`: 시간 많이 드는 계산/복합문제

80점 목표 과목은 L1~L3를 먼저 거의 확실하게 만든 뒤 L4를 추가한다. 수리는 L1~L2 중심으로 방어한다.

---

## 8. 자료 보정 주기

매주 금요일에 다음 데이터를 보고 다음 주 자료량을 바꾼다.

- 단원별 정답률
- 문제태그별 정답률
- 평균 풀이시간
- `모름/헷갈림/공식선택/계산/독해/시간` 오답 비율

4주마다 인터넷의 최신 공식공고·복원자료·현행 교재를 다시 확인해 범위와 유형을 갱신한다.

## 9. 현재 인터넷 자료에서 확인된 설계 근거

- 서울교통공사 대비 현행 에듀윌 교재는 최근 3개년 NCS 복원, 2021 복원, 9호선 복원 100제와 기계일반 전공 모의고사를 제공한다.
- 코레일 대비 현행 에듀윌 교재는 2025년 3월·9월 오전/오후·11월 기출복원 세트와 전공 기출복원/변형 모의고사를 제공한다.
- 현행 코레일 기계일반 문제집은 열역학, 유체역학(유체기계 포함), 재료역학, 기계재료, 기계설계의 큰 축으로 구성되어 있으며 문제를 상·중·하로 나누어 중 난도를 실제 주요문제 수준으로 안내한다.
- NCS 공식 사이트는 의사소통·수리·문제해결 등을 포함한 직업기초/직업공통능력 자료와 학습모듈을 제공한다.
