# 전공 혼합 진단 — 60문항

목적: 기계재료·재료역학·기계설계·열역학·유체역학·공작/유압/열전달을 섞어 현재 약점을 찾는다. 공개 기출문장을 복제하지 않은 자체 제작 문제다.

권장시간: 첫 진단 75분 → 2회차 60분 → 최종 50~55분 목표.

태그: D 직접지식 / C 비교 / F 공식선택 / N1 1단계계산 / M 개념+계산.

# 채점표

- 기계재료: 1~8 /8
- 재료역학: 9~18 /10
- 기계설계: 19~28 /10

점수보다 먼저 **영역별 정답률과 오답태그**를 기록한다.

오답코드:
- K: 개념 모름
- C: 개념 혼동
- F: 공식 선택 실패
- A: 산술/계산
- U: 단위
- R: 지문 오독
- T: 시간부족

## 해석
- 80% 이상: 유지+속도훈련
- 65~79%: 정상 학습, 약점단원 20% 보강
- 50~64%: 개념골격 재구축 후 문제량 증가
- 49% 이하: 해당 과목 신규진도보다 A급 범위 재학습 우선
