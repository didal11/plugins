# 열역학 — 시험형 완성 자료

목표: 공식을 외워 찍는 것이 아니라 **계(system)를 그리고 에너지 흐름을 판단한 뒤 식을 선택**한다. 계산이 약한 학습자를 기준으로 기본·중간 난도를 확실히 회수한다.

## 0. 계산 루틴

1. 계를 그린다: 닫힌계/열린계
2. 초기·최종 상태를 쓴다.
3. 열 Q, 일 W, 질량유량 방향을 표시한다.
4. 단위를 맞춘다.
5. 제1법칙 또는 상태식 중 무엇이 필요한지 선택한다.
6. 수치 대입 후 부호와 크기를 확인한다.

---

# 1. 상태량과 단위

- 압력 P, 온도 T, 비체적 v, 내부에너지 u, 엔탈피 h, 엔트로피 s 등은 상태량.
- 열 Q와 일 W는 과정량이며 경로에 따라 달라진다.
- 절대온도: `T[K] = t[°C] + 273.15`.
- 비체적 `v = V/m`, 밀도 `ρ = 1/v`.

### 압력
절대압력과 게이지압력:
`P_abs = P_gauge + P_atm`.

# 2. 이상기체

`PV = mRT`, 또는 `Pv = RT`.

이상기체에서 내부에너지 u는 주로 온도의 함수로 다룬다.

비열:
- 정적비열 cv
- 정압비열 cp
- `cp - cv = R`
- 비열비 `k = cp/cv`

# 3. 열과 일

경계일:
`W = ∫ P dV`

P-V 선도에서 과정선 아래 면적은 경계일과 관련한다.

- 팽창: 계가 외부에 일을 하는 방향
- 압축: 외부가 계에 일을 하는 방향

부호규약은 교재 기준을 따른다. 중요한 것은 계산 전 **어느 방향의 에너지 전달인지 말로 먼저 판단**하는 것이다.

# 4. 열역학 제1법칙

## 닫힌계
대표형:
`Q - W = ΔU + ΔKE + ΔPE`
운동·위치에너지 변화를 무시하면 `Q-W=ΔU`.

## 정상류 열린계
단위질량 대표형:
`q - w_s = (h2-h1) + (V2²-V1²)/2 + g(z2-z1)`.

### 장치별 1차 판단
- 노즐: 엔탈피 → 속도, 축일 거의 없음
- 디퓨저: 속도 → 압력/엔탈피 증가 경향
- 터빈: 유체가 축일을 냄
- 압축기: 외부 축일을 유체에 넣음
- 스로틀밸브: 대표적으로 `h1 ≈ h2`
- 열교환기 전체: 외부와 단열 가정 시 유체 간 에너지 교환

# 5. 대표 과정

## 정적 과정
V 일정 → 경계일 0.

## 정압 과정
P 일정 → `W=P(V2-V1)`.

## 등온 이상기체 과정
T 일정 → 이상기체의 ΔU=0.
가역 등온일 대표식 `W=mRT ln(V2/V1)`.

## 단열 과정
Q=0.
가역 단열 이상기체라면 `PV^k=상수` 등 관계 사용.

## 폴리트로픽
`PV^n=상수`.

# 6. 제2법칙과 엔트로피

제1법칙이 에너지 양의 보존을 말한다면 제2법칙은 **과정의 방향성과 에너지 품질**을 다룬다.

- 고온에서 저온으로 자발적 열전달.
- 모든 열을 하나의 사이클에서 100% 일로 바꾸는 열기관은 불가능.
- 고립계 엔트로피는 비가역과정에서 증가, 가역과정에서 일정.

가역 열전달:
`ds = δq_rev/T`.

# 7. 열기관과 효율

열효율:
`η = W_net/Q_in = 1 - Q_out/Q_in`.

카르노 열기관:
`η_C = 1 - T_L/T_H` (절대온도).

고온열원 온도 상승 또는 저온열원 온도 하강 → 카르노 효율 증가.

# 8. 공기표준 사이클

## 오토 사이클
가솔린기관 이상화. 정적 열공급.
대표 효율은 압축비 r가 증가하면 상승.

## 디젤 사이클
정압 열공급.

## 사바테/듀얼 사이클
정적+정압 열공급 조합.

시험은 선도와 `어느 과정에서 열을 공급하는가` 비교를 우선한다.

# 9. 브레이튼 사이클

가스터빈 이상화:
`등엔트로피 압축 → 정압 열공급 → 등엔트로피 팽창 → 정압 방열`.

구성: 압축기-연소기/가열기-터빈.

# 10. 랭킨 사이클

증기동력:
`펌프 → 보일러 → 터빈 → 응축기`.

핵심:
- 보일러: 열공급
- 터빈: 일 발생
- 응축기: 방열
- 펌프: 압력 상승에 일 필요

재열/재생은 효율·습분 등 개선 목적으로 사용.

# 11. 냉동사이클과 COP

냉동기:
`COP_R = Q_L/W`.

히트펌프:
`COP_HP = Q_H/W = COP_R + 1`.

증기압축 냉동 기본:
`압축기 → 응축기 → 팽창밸브 → 증발기`.

- 증발기에서 저온부 열 흡수
- 응축기에서 고온부로 열 방출
- 팽창밸브는 스로틀링, h 일정 근사

# 12. 증기와 건도

포화혼합물에서 건도 x:
`x = 건증기 질량 / 전체 질량`.

혼합물의 비체적·엔탈피 등:
`y = y_f + x(y_g-y_f) = y_f + x y_fg`.

x=0 포화액, x=1 포화증기.

---

# 13. 자주 틀리는 포인트

- °C를 카르노 효율식에 그대로 넣지 않는다. K 사용.
- 정적 과정은 `일=0`이지 `열=0`이 아니다.
- 단열은 `Q=0`이지 온도 일정이 아니다.
- 스로틀은 압력이 크게 변해도 대표적으로 엔탈피 일정.
- 터빈은 일 발생, 압축기는 일 소비.
- 냉동기 COP는 1보다 클 수 있다. 효율 η와 다르다.
