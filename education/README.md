# 교육 자료

이 디렉터리는 서로 다른 장기 학습 과정을 한 저장소 안에서 관리합니다.

## 디렉터리

```text
education/
├── C_CPP/          # C와 C++ 통합 교육
├── RTL/            # Verilog/SystemVerilog RTL 교육
├── Verification/   # SystemVerilog 검증 및 UVM 과정
└── choi/           # 서울교통공사·부산교통공사·코레일 기계직/NCS 장기 커리큘럼
```

## 반도체 설계·검증 과정

1. **C / C++**: RTL 설계 주변 도구, 임베디드 펌웨어, DV/UVM 연계에 필요한 프로그래밍 기반
2. **RTL**: Verilog/SystemVerilog를 사용한 조합논리·순차논리·FSM·파라미터화 설계
3. **Verification**: RTL과 C/C++ 과정을 마친 뒤 진행할 SystemVerilog 검증 및 UVM 과정

```text
C 기초 및 메모리 모델
→ C++ 객체지향 및 자료구조
→ Verilog/SystemVerilog RTL
→ 테스트벤치와 Assertion
→ 객체지향 SystemVerilog
→ UVM
→ AMBA 기반 설계 검증
```

## choi 철도공기업 기계직 과정

`choi/`는 서울교통공사·부산교통공사·한국철도공사 중 최소 한 곳 이상 필기 합격권 진입을 목표로 합니다.

- 전공 공통코어 우선
- 수리 외 전공/NCS 80점권 목표
- 수리는 40~50점 방어
- 주말 정규학습 없음
- 평일 주 28시간 장기운영
- 법령은 별도 2주 블록

세부 내용은 `choi/README.md`와 `choi/CURRICULUM.md`를 참고합니다.
