# Session 1 — 90분

## 1. 힘을 받는 재료를 다섯 질문으로 본다

1. **강도**: 큰 하중을 얼마나 견디는가?
2. **경도**: 표면이 눌리거나 긁히는 것을 얼마나 견디는가?
3. **인성**: 파괴될 때까지 에너지를 얼마나 흡수하는가?
4. **연성**: 끊어지기 전에 얼마나 소성변형하는가?
5. **취성**: 거의 늘어나지 않고 갑자기 깨지는 경향이 큰가?

### 즉시 O/X
- 강도와 경도는 같은 뜻이다. → X
- 연성이 큰 재료는 파괴 전 소성변형이 큰 편이다. → O
- 강도가 높으면 인성도 반드시 높다. → X
- 취성은 파괴 전 소성변형이 작은 성질과 관련된다. → O

## 2. 탄성·소성·강성

- 탄성변형: 하중 제거 후 원상복귀.
- 소성변형: 하중 제거 후 영구변형.
- 강성: 변형하기 어려운 정도. 탄성계수 E와 연결.

### 시험 함정
`강성이 크다 = 파괴강도가 반드시 크다`가 아니다. 변형 저항과 파괴강도는 다른 개념이다.

## 3. 응력-변형률 선도

큰 순서:
`비례영역 → 탄성영역 → 항복 → 가공경화 → 최대 인장강도 → 네킹 → 파단`

### 기억할 의미
- 비례한도: σ와 ε가 비례하는 선형영역 끝.
- 탄성한도: 제거 후 원상복귀 가능한 범위의 끝.
- 항복: 소성변형이 본격적으로 시작.
- 인장강도: 공칭응력 최대.
- 파단: 최종 파괴.

### 그림을 그려야 한다
노트에 좌표축을 그린다.
- 세로: 응력 σ
- 가로: 변형률 ε
- 직선구간 → 항복 → 상승 → 최대 → 하강/파단의 큰 모양만 그린다.

정확한 재료별 곡선 모양보다 각 구간의 **물리적 의미**를 먼저 잡는다.

## 4. 인장시험에서 무엇을 얻나

대표:
- 항복강도
- 인장강도
- 연신율
- 단면수축률

연신율과 단면수축률은 연성 판단과 연결한다.

1. 표면 긁힘 저항은? ①강도 ②경도 ③인성 ④연성

# Session 2 — 60분

## 1. 경도시험

### 브리넬
- 강구 또는 초경구 압입
- 비교적 큰 압흔
- 압흔 크기를 이용

### 로크웰
- 압입 깊이를 이용해 빠르게 경도 판정
- 현장 측정에 편리

### 비커스
- 다이아몬드 사각뿔 압입자
- 작은 압흔·광범위한 재료에 활용

첫날에는 세부 시험하중 수치보다 **압입자/측정방식의 차이**를 우선한다.

## 2. 충격시험

갑작스러운 충격하중에 대한 흡수에너지/인성을 본다.
대표: 샤르피, 아이조드.

## 3. 피로

반복응력으로 파괴되는 현상. 최대응력이 항복강도보다 낮아도 반복되면 파괴될 수 있다.

### 피로의 시험형 핵심
- 반복하중
- 응력집중에 민감
- 표면상태가 중요
- S-N 선도와 연결

## 4. 크리프

고온에서 일정한 응력이 장시간 작용할 때 시간에 따라 변형이 증가하는 현상.

비교:
- 피로 = 반복하중/반복횟수
- 크리프 = 고온/시간

# Session 3 — 전공 25문항 / 60분

첫 회는 25문항을 35분 안에 푼다. 남은 25분은 표시한 문제 검토에 사용한다.

문제는 `01_MECHANICAL_MATERIALS.md`의 20문항과 아래 5문항을 합쳐 사용한다.

21. [C] 인장시험에서 연성과 가장 직접 연결되는 값은? ①연신율 ②비열 ③밀도만 ④열팽창계수만
22. [C] 탄성영역 내에서 하중을 제거하면? ①영구변형만 남음 ②원상복귀 ③항상 파단 ④반드시 담금질됨
23. [D] 경도시험이 아닌 것은? ①브리넬 ②비커스 ③로크웰 ④샤르피
24. [C] 피로수명을 개선하는 방향으로 일반적으로 적절한 것은? ①심한 응력집중 유지 ②표면결함 감소 ③노치 증가 ④반복응력 증가
25. [C] 크리프에 대한 설명으로 옳은 것은? ①시간의존 변형 ②반드시 상온의 순간충격 ③유량 변화만 ④기어마모만

정답: 21① 22② 23④ 24② 25①

## 기록
각 문제 옆에 D/C/G 중 하나를 적는다.
- D: 직접지식
- C: 개념비교
- G: 선도/그림

그리고 틀린 이유를 K/C/R/T 중 하나로 적는다.
- K: 몰랐음
- C: 헷갈림
- R: 지문오독
- T: 시간
