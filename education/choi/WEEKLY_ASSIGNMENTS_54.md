# 54주 실행 과제표

이 문서는 `CURRICULUM.md`의 큰 단계를 실제 주간 과제로 내린 실행표다. 시험일정은 무시하고, 주 28시간(월~목 6h, 금 4h)을 기준으로 한다. 토·일은 정규학습 없음.

공통 규칙:
- 전공 신규 12~16h + 전공 문제/복습 2~6h
- NCS 10h 내외
- 금요일은 누적세트/오답 중심
- 과목별 이동은 주차보다 점수기준이 우선. 미달 시 다음 주 신규량을 20~30% 줄이고 보강한다.

# 주별 세부 운영

## 월~목 6h
- Block A 2h: 신규 전공 개념/쉬운 예제
- Block B 2h: 전공 문제·오답
- Block C 2h: NCS

## 금 4h
- 전공 2h: 제한시간 누적세트
- NCS 2h: 제한시간 세트 + 주간 기록

# 주차 미달 시 처리

예: Week 9인데 Week 8 보 문제 정답률이 55%라면 Week 9를 통째로 취소하지 않는다.

- 신규 18h 중 4~6h를 Week 8 약점에 재배정
- 신규 단원은 핵심 A급만 진입
- 금요일 누적평가에서 회복 여부 확인

같은 과목이 2주 연속 60% 미만이면 `REBUILD` 상태로 전환해 1주 동안 개념골격+기본문제로 재구축한다.

# 54주 종료 뒤 유지

목표권 진입 후 주당:
- 전공 혼합 2세트
- NCS 혼합 2세트
- 오답 재풀이 2h
- 기관별 최신공고가 나오면 형식만 재조정

법령은 별도 기관별 집중블록에서 추가한다.
