# 서울교통공사·부산교통공사·코레일 기계직 장기 커리큘럼

## 0. 설계 전제

이 과정은 시험일정을 무시하고 장기 실력을 만드는 기준으로 설계한다.

- 주말: 정규 학습 없음
- 평일 기본 순공: **주 28시간**
  - 월~목 6시간
  - 금 4시간
  - 금요일 추가 2시간은 선택 보충이며 필수 진도에 포함하지 않음
- 법령: 별도 2주 묶음으로 처리하므로 본 커리큘럼에서 제외
- 전공 목표: **모든 과목 80점권**
- NCS 목표: **수리만 40~50점 방어**, 나머지 전 영역 80점권
- 기본 교재: 위을복 기계일반 + 필요 시 계산과목 보조교재/기출 추가
- NCS 기본 교재: 보유 중인 에듀윌 교재
- 학습 방식: `GPT 개념 이해 → 교재 이론 → 예제 → 문제 → 오답 → 누적복습`
- 수학은 별도 장기 선행과목으로 떼지 않고, 전공에서 필요한 순간에 필요한 만큼만 삽입한다.

# 3. 전체 진행 순서

## Phase 1 — 3기관 공통 기반 완성

**예상 14~17주 / 약 390~470시간**

신규 학습 허용 과목은 아래 5개뿐이다.

- 기계재료
- 기계설계
- 의사소통
- 수리
- 문제해결

### 주간 배분

- 전공: **16시간**
- NCS: **12시간**

### 전공 진행 순서

처음부터 두 과목을 동일 비율로 하지 않는다.

1. 기계재료를 주력으로 시작하고 기계설계는 보조로 진입
2. 기계재료 1회독이 끝나면 기계설계를 주력으로 승격
3. 기계재료는 문제·오답·누적복습으로 유지

권장 초기 배분:

- 기계재료 10h/주
- 기계설계 6h/주

기계재료 1회독 후:

- 기계재료 5h/주
- 기계설계 11h/주

### NCS 진행 순서

- 의사소통: 매주 지속 훈련
- 문제해결: 매주 지속 훈련
- 수리: 최소 방어선만 구축

권장 배분:

- 의사소통 5h/주
- 문제해결 5h/주
- 수리 2h/주

수리는 어려운 고난도 유형을 장기간 붙들지 않는다. 비율·백분율·평균·거리/속력/시간·쉬운 자료해석 등 맞힐 문제를 분명히 정하는 것이 목적이다.

### Phase 1 종료 조건

아래가 모두 충족되어야 Phase 2 신규과목을 연다.

- 기계재료: 최근 혼합 문제 3회 평균 80점 이상
- 기계설계: 최근 혼합 문제 3회 평균 80점 이상
- 의사소통: 최근 3세트 평균 80점 이상
- 문제해결: 최근 3세트 평균 80점 이상
- 수리: 쉬운 문제 선별 기준이 잡히고 목표 범위에서 40~50점 수준 확보
- 틀린 문제의 절반 이상을 '왜 틀렸는지' 말로 설명 가능

## Phase 2 — 가장 빠른 추가 합격 경로: 열역학

**예상 5~6주 / 약 140~170시간**

3기관 공통 이후에는 **서울교통공사+코레일 공통인 열역학을 먼저** 연다.

이유는 간단하다. 3기관 공통을 이미 마친 상태에서 코레일 전공의 남은 추가 범위가 열역학 하나이므로, 최소 추가 학습으로 한 기관의 전공 범위를 완성할 수 있다. 동시에 서울교통공사 준비에도 그대로 남는다.

### 주간 배분

- 열역학 신규학습: **20h/주**
- Phase 1 유지복습: **8h/주**

유지복습 예시:

- 기계재료 1.5h
- 기계설계 2h
- 의사소통 2h
- 문제해결 1.5h
- 수리 1h

### 열역학 학습 순서

1. 필요한 수학만 즉시 보충: 분수식, 비례식, 단위변환, 제곱/로그 기초
2. 상태량·압력·온도·비체적
3. 열과 일
4. 내부에너지·엔탈피
5. 열역학 제1법칙
6. 정압·정적·등온·단열 과정
7. 제2법칙·엔트로피
8. 카르노·오토·디젤·사바테 사이클
9. 랭킨·냉동 사이클
10. 혼합 기출과 오답

### 열역학 원칙

공식을 먼저 외우지 않는다.

`현상 그림 → 물리적 의미 → 식이 만들어지는 이유 → 매우 쉬운 숫자 예제 → 일반 문제`

순서로 학습한다.

### Phase 2 종료 조건

- 열역학 혼합 문제 최근 3회 평균 80점 이상
- 주요 공식에 대해 '언제 왜 쓰는 식인지' 설명 가능
- 틀린 문제에서 계산 실수와 개념 오류를 구분 가능

## Phase 3 — 서울교통공사 + 부산교통공사 공통 확장

**예상 9~11주 / 약 250~310시간**

### 주간 배분

- 전공 17h
- NCS 9h
- 이전 단계 유지복습 2h

### 권장 진행 순서

1. 기계공작법
2. 자원관리
3. 정보능력
4. 유체기계

단, 한 과목을 완전히 닫고 다음 과목으로 넘어가지는 않는다.

초반:
- 기계공작법 10h
- 유체기계 7h
- 자원관리 5h
- 정보능력 4h

기계공작법이 1회독 완료되면 유체기계 비중을 늘린다.

### 이유

기계공작법은 비교적 이론·암기 비중이 높아 초반에 빠르게 성취감을 만들기 좋다. 유체기계는 유체역학보다 먼저 장치와 현상을 익혀두면 이후 유체역학을 배울 때 추상도가 낮아진다.

### Phase 3 종료 조건

- 기계공작법 80점권
- 유체기계 80점권
- 자원관리 80점권
- 정보능력 80점권
- Phase 1~2 과목이 복습 세트에서 급격히 무너지지 않음

이 단계가 끝나면 부산교통공사 기준 법령을 제외한 핵심 범위가 사실상 완성된다.

# 5. 한 단원을 공부하는 표준 사이클

한 단원은 아래 순서를 반복한다.

1. **사전 구조 파악** — 10~20분
   - 이 단원이 무엇을 설명하는지 큰 그림만 확인
2. **GPT 개념 설명** — 20~40분
   - 이해되지 않는 개념을 그림·비유·원인 중심으로 질문
3. **교재 정독** — 40~80분
4. **기본 예제** — 30~60분
5. **단원 문제** — 40~80분
6. **오답 분류** — 20~30분
   - 개념 부족 / 공식 선택 오류 / 계산 오류 / 문제 독해 오류
7. **다음날 10분 회상**
8. **1주 뒤 재시험**

노트는 강의 내용을 다시 필사하는 용도로 쓰지 않는다. 오직 '내가 틀린 이유'와 '헷갈리는 비교표'만 기록한다.

# 6. 계산 약점을 위한 별도 규칙

수학 기초가 약하므로 계산과목에서 다음 원칙을 강제한다.

- 계산이 막혔을 때 전공 개념 부족과 수학 조작 부족을 분리한다.
- 이항, 분수, 비례식, 단위변환, 제곱근, 로그 등이 필요하면 그 순간 20~60분짜리 미니 수학 보충을 삽입한다.
- '중학교 수학 전체를 먼저 끝내고 전공으로 복귀'하는 방식은 사용하지 않는다.
- 한 문제에서 계산 때문에 15분 이상 정체되면 풀이를 분해해서 어떤 연산에서 막혔는지 확인한다.
- 계산 실수는 오답노트에 정답 풀이가 아니라 실수 패턴을 기록한다.

# 7. NCS 영역별 전략

## 의사소통

가장 많은 장기훈련이 필요한 영역이다.

- 꼼꼼히 모든 문장을 동일 강도로 읽는 습관을 줄임
- 목적 → 결론 → 근거 구조를 찾는 연습
- 처음에는 정확도, 이후 시간 단축
- 매주 끊지 않고 지속

## 수리

유일한 저목표 영역이다.

- 40~50점 방어가 목적
- 쉬운 유형 선별 능력을 훈련
- 고난도에 매몰되지 않음
- 암산·자료해석 기본기를 짧게 반복

## 문제해결

강점 후보 영역이다.

- 조건을 표/그림으로 구조화
- 추리형 문제는 풀이 절차를 정형화
- 계산형 문제는 수리 목표와 분리

## 자원관리·정보능력

표·데이터 해석이 필요한 만큼 반복 훈련하되, 복잡한 계산보다 정보 선택과 절차 파악에 초점을 둔다.

## 조직이해·대인관계·직업윤리·자기개발·기술능력

암기만 하지 않고 상황 판단 기준을 문장으로 설명할 수 있도록 학습한다.

# 8. 전체 예상 기간

정규 학습을 주 28시간으로 유지하면 대략 **45~55주** 범위를 예상한다.

- Phase 1: 14~17주
- Phase 2: 5~6주
- Phase 3: 9~11주
- Phase 4: 17~21주

즉 약 **10~13개월**의 장기 과정으로 본다.

이는 달력에 맞춘 강제 진도가 아니다. 각 Phase는 점수 기반 종료 조건을 충족하면 앞당겨질 수 있고, 부족하면 늘어난다.

---

# 9. 중요한 운영 원칙

1. **공통 범위가 먼저다.** 신규과목은 Phase 순서를 건너뛰지 않는다.
2. 단, 이미 배운 공통과목의 유지복습은 다음 Phase에서도 계속한다.
3. 한 과목을 100% 완벽하게 만들기 위해 다른 공통과목을 몇 달 동안 막아두지 않는다.
4. 80점 목표는 '교재를 다 읽었다'가 아니라 **시간을 제한한 혼합 문제에서 재현되는 점수**로 판단한다.
5. 한 주를 망쳤다고 주말을 강제로 학습일로 바꾸지 않는다. 다음 주 계획을 조정한다.
6. 매 4주마다 과목별 실제 점수와 공부시간을 기록해 예상시간을 재보정한다.
7. 성취가 너무 느린 과목은 무작정 시간을 더 붓기보다 오답 유형과 학습법부터 바꾼다.

# 10. 합격 가능성을 위한 경로 해석

목표가 '세 기관을 모두 완벽히 준비'하는 것이 아니라 **세 곳 중 최소 한 곳에 합격**하는 것이라면, 공통과목 우선 전략은 타당하다.

다만 3기관 공통을 끝낸 뒤에도 단순히 2기관 공통 과목을 아무 순서로나 공부하는 것보다 **열역학을 먼저 끝내는 것이 효율적**이다.

- 3기관 공통 완료
- 열역학 완료 → 코레일 전공 범위가 가장 빠르게 완성
- 서울+부산 공통 완료 → 부산 범위까지 완성
- 마지막 서울 추가 범위 → 가장 넓은 서울교통공사 범위 완성

따라서 최종 학습 흐름은 다음과 같다.

```text
[3기관 공통]
기계재료 + 기계설계
의사소통 + 수리(방어) + 문제해결
        ↓
[서울+코레일 공통]
열역학
        ↓
[서울+부산 공통]
기계공작법 + 유체기계
자원관리 + 정보능력
        ↓
[서울 추가]
재료역학 + 유압기기 + 유체역학
직업윤리 + 대인관계 + 조직이해 + 자기개발 + 기술능력
```

이 순서가 현재 목표와 학습 특성을 기준으로 한 기본 커리큘럼이다.
