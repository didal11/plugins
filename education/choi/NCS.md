# NCS 세부 커리큘럼

수리능력만 40~50점 방어 목표이며, 나머지 영역은 80점권을 목표로 한다.

## 공통 원칙

NCS는 지식을 다 외운 뒤 푸는 시험으로 보지 않는다.

`유형파악 → 정확도 → 제한시간 → 선별 → 실전세트` 순서로 간다.

매 문제 오답 이유는 아래 5개 중 하나로 표시한다.

- 독해실패
- 조건정리 실패
- 계산실수
- 지식부족
- 시간관리 실패

---

# 1. 의사소통능력 — 100~140h / 목표 80

현재 가장 큰 약점은 읽는 속도와 한 번에 핵심을 잡는 능력이다. 따라서 초반부터 매주 끊지 않고 훈련한다.

## 학습 순서

1. 문단의 역할 찾기
2. 주제/요지 찾기
3. 사실일치/불일치
4. 문서 목적 파악
5. 문장배열
6. 빈칸/문맥
7. 공문서·업무문서
8. 긴 지문 시간제한

## 읽기 규칙

문장을 전부 같은 비중으로 읽지 않는다.

먼저 찾는 것:
- 글의 목적
- 결론
- 조건
- 예외
- 비교대상

## 훈련 단계

- 1단계: 시간 제한 없이 85% 정확도
- 2단계: 문제당 제한시간 설정
- 3단계: 세트 단위 제한시간
- 4단계: 다른 NCS 영역과 섞어서 실전

---

# 2. 문제해결능력 — 60~80h / 목표 80

비교적 적성에 맞는 영역으로 본다. 퍼즐·조건정리를 좋아하고 표나 그림을 직접 그려 푸는 습관을 적극 활용한다.

## 학습 순서

1. 문제 원인/목표 구분
2. 조건명제
3. 참/거짓
4. 순서배치
5. 위치배치
6. 일정/업무배정
7. 규칙찾기
8. 의사결정
9. 사례형 문제

## 원칙

조건이 3개 이상이면 머릿속에서만 풀지 않는다.

- 표
- 화살표
- 순서선
- O/X

중 하나로 외부화한다.

---

# 3. 수리능력 — 30~50h / 목표 40~50

수리는 버리는 과목이 아니라 **회수 가능한 쉬운 문제만 확실히 챙기는 방어영역**으로 정의한다.

## 반드시 챙길 범위

1. 사칙연산 정확도
2. 분수/소수
3. 비율
4. 백분율
5. 증감률
6. 평균
7. 일차방정식
8. 거리·속력·시간
9. 단순 표 읽기
10. 단순 그래프 읽기

## 후순위/포기 후보

- 복잡한 자료해석
- 계산량이 큰 다단계 문제
- 난도가 높은 응용수학
- 여러 표를 동시에 결합해야 하는 문제

## 시험 선별 규칙

문제를 20~30초 봤는데 계산경로가 안 보이면 표시하고 넘긴다.

목표는 `어려운 문제를 풀 수 있음`이 아니라 `쉬운 문제를 놓치지 않음`이다.

---

# 4. 자원관리능력 — 40~60h / 목표 80

## 범위

- 시간자원
- 예산자원
- 물적자원
- 인적자원
- 우선순위
- 일정관리
- 업무배분

## 학습법

계산이 섞이면 먼저 '무엇을 최소화/최대화하는가'를 적는다.

표에서 자원을 각각 분리한 뒤 조건을 하나씩 적용한다.

---

# 5. 정보능력 — 50~70h / 목표 80

## 범위

1. 컴퓨터 기본구조
2. 하드웨어/소프트웨어
3. 운영체제
4. 네트워크 기초
5. 인터넷
6. 정보보안
7. 데이터와 데이터베이스 기초
8. 스프레드시트 기초개념
9. 정보검색
10. 정보윤리

## 약점대응

엑셀을 실제 업무수준으로 마스터할 필요는 없지만, 셀/함수/정렬/필터/표의 구조가 무엇인지 정도는 직접 프로그램을 열어 확인한다.

---

# 6. 조직이해능력 — 30~45h / 목표 80

관심과 적성이 비교적 좋은 영역이다.

## 범위

- 조직의 목적
- 조직구조
- 경영일반
- 부서별 역할
- 업무 프로세스
- 조직문화
- 국제감각 기초

## 학습법

용어만 외우지 말고 실제 공기업 조직도에 대입한다.

예: 인사/재무/구매/안전/운영/시설 부서가 어떤 정보를 주고받는지 흐름도로 연결한다.

---

# 7. 대인관계능력 — 20~30h / 목표 80

## 범위

- 팀워크
- 리더십
- 갈등관리
- 협상
- 고객서비스

## 선택지 판단 원칙

대부분의 상황형 문제에서 우선순위는 다음과 같다.

1. 사실 확인
2. 상대 의견 청취
3. 규정/조직목표 확인
4. 직접적인 해결 시도
5. 필요하면 상급자/절차 활용

감정적 대응이나 즉시 회피는 후순위로 둔다.

---

# 8. 직업윤리 — 10~20h / 목표 80

강점 예상 영역이다.

## 범위

- 근로윤리
- 공동체윤리
- 책임
- 성실
- 청렴
- 규정준수
- 공익

## 전략

문제를 과도하게 꼬아서 해석하지 않는다.

`법/규정 위반 여부 → 공익 → 책임성 → 협업` 순서로 판단한다.

---

# 9. 자기개발능력 — 25~40h / 목표 80

## 범위

- 자기인식
- 자기관리
- 경력개발
- 목표설정
- 역량개발

## 약점대응

목표설정이 추상적으로 느껴지므로 SMART 방식처럼 구조화된 틀을 사용한다.

문제에서 목표가 나오면:
- 구체성
- 측정가능성
- 실현가능성
- 관련성
- 기한

을 체크한다.

---

# 10. 기술능력 — 40~60h / 목표 80

기계·장치 원리는 흥미가 있지만 전기전자·구조도 추론은 약점으로 본다.

## 범위

1. 기술의 의미와 선택
2. 기술시스템
3. 장비·도구 사용
4. 작업절차
5. 안전
6. 기초 기계원리
7. 기초 전기전자
8. 기술문제 해결

## 학습법

텍스트만 읽지 않는다.

가능하면:
- 간단한 그림
- 블록도
- 흐름도
- 실제 장치 사진

을 같이 본다.

---

# 11. NCS 주간훈련의 변화

## 1~19주

- 의사소통 4h
- 문제해결 4h
- 수리 2h

목표: 핵심 3영역의 기본기와 시간습관 만들기.

## 20~27주

- 의사소통 4h
- 자원관리 2h
- 정보능력 2h
- 문제해결 1h
- 수리 1h

## 28~36주

- 자원관리 3h
- 정보능력 3h
- 의사소통 2h
- 문제해결 1h
- 수리 1h

## 37~46주

서울교통공사 추가 5영역을 열고 기존 영역을 유지한다.

## 47~54주

영역별 공부가 아니라 기관별 실전세트로 전환한다.

---

# 12. NCS 복습과 성적판정

매주 금요일에 영역별로 아래를 기록한다.

| 지표 | 기록 |
|---|---|
| 정답률 | % |
| 평균 풀이시간 | 초/문제 |
| 시간초과 수 | 문항 |
| 계산실수 수 | 문항 |
| 독해실수 수 | 문항 |
| 버린 문제 수 | 문항 |

수리 외 영역은 최근 5세트 중 4세트 이상 80점이면 유지단계로 낮춘다.

수리는 40~50점이 나오고 쉬운 문제의 정답률이 80% 이상이면 추가 투자하지 않는다.
