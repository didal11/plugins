# 시험자료 기반 커리큘럼 보정

이 문서는 `choi` 커리큘럼을 단순 교과목 목차가 아니라 **실제 철도공기업 필기시험 형태에 맞게 보정**하기 위한 기준이다.

## 1. 자료를 어떤 순서로 믿는가

자료의 신뢰도를 다음 순서로 둔다.

1. **당해 연도 공식 채용공고/공식 출제범위** — 시험범위와 문항구조의 최우선 근거
2. **최근 기출복원 교재·공개 기출복원 자료** — 실제 출제유형·난도·키워드의 근거
3. **철도공기업 전문학원 공개 커리큘럼** — 수험시장에서 실제로 배정하는 과목별 학습량의 보조 근거
4. **응시후기/커뮤니티** — 시간압박·체감난도 판단에만 제한적으로 사용

공식 문제지가 전부 공개되지 않는 시험이므로 `최근 몇 년 기출에서 정확히 몇 %` 같은 숫자를 근거 없이 확정하지 않는다. 대신 여러 복원자료가 공통으로 지지하는 내용은 **고신뢰 빈출범위**, 출판사 한 곳만 다루는 내용은 **보조범위**로 구분한다.

## 3. 커리큘럼에 반영하는 핵심 수정

### 수정 A — `개념을 다 배우고 나중에 문제` 방식 금지

철도공기업 기계일반은 범위가 넓고 객관식 문제 처리 능력이 중요하므로 첫 주부터 문제를 붙인다.

권장 비율:

- 첫 2주: 개념 60 / 문제 40
- 3~8주: 개념 45 / 문제 55
- 1회독 후: 개념보강 25 / 문제·기출·오답 75

### 수정 B — 한 미세개념에 2시간씩 쓰지 않는다

예: `강도/경도/인성/연성/취성`만 2시간 강의하는 식으로 운영하지 않는다.

시험 단위로 묶는다.

예시:

`기계적 성질 → 응력-변형률 선도 → 인장시험 → 경도/충격/피로/크리프 → 관련 객관식`

을 하나의 학습 묶음으로 처리한다.

### 수정 C — 공통코어 5과목을 모두 실제 문제와 함께 조기 노출

최우선 코어:

1. 기계재료
2. 재료역학
3. 기계설계
4. 열역학
5. 유체역학

다만 학습자의 계산 약점을 고려하여 첫 달에는 기계재료를 주력으로 성취감을 만들고, 재료역학의 응력/변형률/단위부터 동시에 시작한다.

### 수정 D — 공부시간은 `출제빈도`와 `개인 난이도`를 분리

재료역학에 150시간을 잡는다고 해서 시험에서 재료역학이 기계재료보다 2배 많이 나온다는 뜻이 아니다.

- **시험 가중치:** 실제 복원·출제범위에서의 중요도
- **개인 시간 가중치:** 수학/계산 취약 때문에 같은 점수까지 걸리는 시간

두 값을 분리한다.

현재 개인 시간예산은 다음과 같이 유지한다.

| 과목 | 80점권 개인 시간예산 |
|---|---:|
| 기계재료 | 60~75h |
| 기계설계 | 90~120h |
| 재료역학 | 130~160h |
| 열역학 | 120~150h |
| 유체역학(+유체기계) | 130~165h |

이 차이는 주로 개인 난이도 차이다.

## 4. 전공 문제유형 분류표

앞으로 모든 전공 문제는 다음 태그 중 하나로 기록한다.

- `D` 직접지식/암기
- `C` 개념비교/옳고 그름
- `G` 그림·선도·상태도
- `F` 공식선택
- `N1` 1단계 수치대입
- `N2` 2단계 이상 계산
- `M` 개념+계산 혼합

그리고 단원 태그를 함께 붙인다.

예:

`기계재료/열처리/C`
`기계재료/Fe-C/G`
`재료역학/축하중/N1`
`열역학/단열과정/M`

목적은 공부시간이 아니라 **실제 틀리는 문제 종류를 데이터화하는 것**이다.

## 5. 4주마다 보정하는 방법

4주마다 다음 데이터를 모은다.

1. 단원별 문제 수
2. 정답률
3. 한 문제 평균시간
4. 오답원인
5. 문제유형 태그

조정 규칙:

- 정답률 85% 이상 + 시간 안정 → 학습시간 20~30% 축소, 유지복습 전환
- 70~84% → 현재 비율 유지
- 50~69% → 다음 4주에 해당 단원 시간을 25% 증가
- 49% 이하 → 원인 분리 후 개념 재구축
- 계산실수가 절반 이상 → 새 공식을 더 배우지 말고 계산 정확도 훈련
- 시간부족이 절반 이상 → 난도 문제가 아니라 선별/풀이순서 훈련

## 6. Day 1부터 적용할 변경

첫날은 순수 개념강의 4시간으로 쓰지 않는다.

### 전공 4시간

1. **90분 — 기계재료 기초 묶음**
   - 강도/경도/인성/연성/취성
   - 탄성/소성
   - 응력-변형률 선도의 큰 그림
   - 인장시험

2. **60분 — 재료시험 묶음**
   - 경도시험의 목적
   - 충격/피로/크리프의 구별
   - 세부 암기는 1회독 후 강화

3. **60분 — 시험형 객관식 20~30문항**
   - 직접암기/비교/선도 문제를 섞음
   - 처음부터 점수보다 오답유형 기록

4. **30분 — 오답 정리**

### NCS 2시간

- 의사소통 1시간 진단
- 문제해결 1시간 진단

첫날 목표는 `배웠다`가 아니라 **현재 정답률·속도·오답유형의 기준선을 만드는 것**이다.
